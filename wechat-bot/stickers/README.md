# 表情包素材

把 `.gif` / `.png` / `.jpg` / `.webp` 丢进这个目录，机器人就会随机挑着发。
GIF 在微信里会动，效果和表情包一样。

没素材也不影响：`stickerReply` 开着时，没有图会自动退回**微信内置表情**
（点表情面板选一格，是真表情消息）。

## 什么时候会发

- 模型自己想发（回复里带 `[[表情包]]` 标记）
- 对方发来表情时（`emojiOnEmoji` 概率）
- 偶尔自己冒一个（`emojiProbability` 概率）

## 注意

- 图别太大，微信压缩后动图容易糊。几十 KB 到 200 KB 比较合适。
- 文件名随意，但别用中文名以外的怪字符，发送时要走剪贴板路径。
- 这个目录里的图**会进 git**。不想公开就自己加进 `.gitignore`。
